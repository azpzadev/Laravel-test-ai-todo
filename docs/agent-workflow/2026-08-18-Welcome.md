## 🏛️ Architecture & Decisions
- **Conventions followed:** Web/Blade view, Tailwind v4, dark-mode via OS `prefers-color-scheme` (no `.dark` toggle), PHPUnit tests extending `Tests\TestCase`. **No backend layers added** — this is a static UI, so the project's Controller→Repository→Service→Model architecture was intentionally NOT invoked (correctly, per issue scope).
- **Key decisions:**
  - Task is a **static UI mockup**, not CRUD. Route stays `Route::get('/', fn () => view('welcome'))`. Hardcoded 5-todo sample array drives both stats and the card list (single source of truth).
  - **Pre-compiled Tailwind bundle constraint:** there is no `public/build`, so only utility classes already in the inline `<style>` fallback render. All classes were restricted to bundled ones. Where a needed utility was absent: `line-through` → inline `style` (with explanatory comment); Completed badge border → bundled `border-[#e3e3e0] dark:border-[#3E3E3A]` (keeping red text); green "completed" accent → reused existing accent `text-[#f53003]` since green utilities aren't bundled; stats bar → `flex` (no `grid-cols-3` in bundle).
  - Preserved `<title>`, `@fonts`, and the load-bearing `@vite/@else <style>` fallback block verbatim.
- **Assumptions / trade-offs:** Sample todo titles, `M j, Y` date format, and `No due date`/`Completed`/`Pending` wording are architect-chosen defaults. One sample (`Call the dentist`) uses null description + null due_date to exercise nullable rendering paths.
- **Mismatches found:** None. The global CLAUDE.md CRUD architecture does not apply to a static view; this was a deliberate, scope-correct deviation, not a conflict.
