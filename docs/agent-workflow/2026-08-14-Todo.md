## 🏛️ Architecture & Decisions
- **Conventions followed:** Layered `Request → Controller → Repository → Service(Interface) → Model` per the user's global standard and explicit request ("DTO, service, Action, clean code"). Fresh greenfield skeleton — no prior layered code to contradict. `final readonly` DTO, one `JsonResource`, FormRequests for validation, validation/log messages centralized in `config/todo.php` (zero hardcoded strings), structured CRUD logging.
- **House-style match (load-bearing):** `app/Models/User.php` configures Eloquent via **PHP attributes** `#[Fillable([...])]` / `#[Hidden([...])]` and a `casts(): array` method — NOT legacy `protected $fillable`. Verified directly; `Todo` matches this style. This is the one place the user's global CLAUDE.md (which implies `$fillable`) and the actual code diverge — per precedence, **code wins** and the attribute style was used.
- **Key decisions:**
  - API routing was **not** registered in this skeleton — added `api:` to `bootstrap/app.php->withRouting()` and created `routes/api.php` by hand. Deliberately did **not** run `php artisan install:api` to avoid pulling Sanctum (no auth required).
  - Rate limiting via inline `throttle:60,1` (the `api` named limiter ships with `install:api`, which we avoided).
  - Interface→implementation binding placed in existing `AppServiceProvider::register()` — one binding doesn't justify a new provider.
  - `destroy()` returns `204 No Content` (not a resource of a deleted model).
  - Partial-update fix: `TodoData::changesFromRequest()` returns only keys present in `$request->validated()` (via `array_key_exists`), so absent keys are preserved and an explicit `null` still clears — distinguishing "absent = keep" from "present-null = set null".
  - `index` paginated via `config('todo.pagination.per_page')` (default 15); migration indexes `created_at` (the actual sort column) and drops the speculative `completed`/`due_date` indexes.
- **Assumptions / trade-offs:** Update supports partial PATCH; `due_date` is a calendar date (not datetime); `completed` defaults to false on create; one shared `TodoData` DTO for create/update. `TodoService::update(Todo, TodoData)` (full replace) retained alongside `applyChanges(Todo, array)` (partial) because the un-editable unit test binds to `update()` — both paths are tested.
- **Mismatches found:** global CLAUDE.md `$fillable` vs code's `#[Fillable]` attribute (resolved in favour of code, noted above).
